# 封面三段式设计规范（cover-style-guide）

> **定稿版本 v14**（2026-10-01 用户验收）。配套模板：`reference/templates/cover-card/`（配方已同步）。
> 适用：竖版 1080×1920 短视频封面，首帧即封面（`ffmpeg -ss 0 -frames:v 1` 抽帧）。

## 1. 为什么要把封面定稿固化

- **资产会丢**：封面迭代发生在 /tmp 工作目录，一次清盘就没了；配方不落文档，下次只能凭记忆重调十几轮。
- **配方 ≠ 模板**：demo 里的魔法数（旋转角、羽化半径、透明度）只有写进模板和规范，才能被下一次直接复用，而不是重新试错。
- **验收标准要冻结**：用户多轮反馈收敛出的规则（序号顺序、张角、安全区、分图）必须写成硬约束，避免后续生成跑偏回退。

## 2. 三段式结构（自上而下）

```
┌─────────────────────────┐
│  ① 冲击力标题（3行）      │ y140 起（安全区上沿）
│  ② 5张编号卖点卡（弧形）  │ 顶1 / 二排2·3 / 底排4·5
│  ③ 出镜主体（羽化无边框） │ 顶部顶到中卡底部
└─────────────────────────┘
```

### 2.1 第一段：冲击力标题
- 字体：**优设标题黑**（单一 Regular 字重，勿用 font-weight 变粗）
- 逐词混排（一行内 2-3 个 `<span class="w">`，字号 150-210px 按词强调）
- 白/金(#ffd21e)/绿(#45f26b) 三色 + 18px 深色描边（`paint-order: stroke fill`）+ 5 层 3D 挤出 text-shadow + 同色泛光
- 顶部对齐 **y140**（平台 UI 遮挡安全区上沿）

### 2.2 第二段：5 张编号卖点卡
- **序号规则（定稿硬约束）**：顶中=1，二排左=2 右=3，底排左=4 右=5。换文案时号跟卡片位置走，不重排卡片。
- 卡片规格：宽 340px、圆角 30px、绿边 5px、**半透明磨砂** `rgba(5,20,16,0.68)` + `backdrop-filter: blur(7px)`（隐约透出背景）
- 内容：编号块（62px 绿渐变）+ 短文案（50px，关键词金色 `<b>`）+ **内联 SVG 图标**（⚠️ 禁用 emoji，headless Chrome 无彩色 emoji 字体会崩成占位图）
- **张角规则（定稿硬约束）**：

| 卡 | 位置 | 旋转 | 说明 |
|---|---|---|---|
| #bd3(1) | 顶中 top:785 | -1.5° | 近水平 |
| #bd2(2) | 二排左 top:875 left:18 | **-10°** | 内边（右）上翘 |
| #bd4(3) | 二排右 top:875 right:18 | **+10°** | 内边（左）上翘 |
| #bd1(4) | 底排左 top:1120 left:58 | **+5°** | 反向展开 |
| #bd5(5) | 底排右 top:1120 right:58 | **-5°** | 反向展开 |

  二排与底排呈 **X 形张角**：2-4、3-5 之间只留轻微错位咬合，无大面积重叠。
- 文字可读性三板斧（半透明卡压亮背景时）：①主体图顶部暗化渐变 ②卡透明度 0.68 ③文字投影 `0 3px 10px rgba(0,0,0,0.85)`

### 2.3 第三段：出镜主体
- **背景与主体必须分图**（两张不同素材，主体叠在背景上才有"出镜"层次）
- 教程类=真人，产品类=真物
- 无边框，径向蒙版羽化融进背景：`mask-image: radial-gradient(ellipse 70% 72% at 50% 50%, #000 55%, rgba(0,0,0,0.5) 78%, transparent 98%)`
- 宽 730px 居中，**top 995**（顶到中卡 #bd3 底部），底部不出安全区 y1790
- 顶部暗化渐变 `.shade`（护住上压的半透明卡文字）

## 3. 安全区（硬约束）

上下平台 UI 遮挡区不入内容：**y 140 - 1790**（上 140 / 下 130）。所有文字、卡片、主体都不得越界。

## 4. 底图处理

- 实景背景：`saturate(1.15) brightness(0.9)` + 上下暗化压边渐变（0.82/0.30/0.32/0.86）
- 背景与主体素材从视频抽帧：
  ```bash
  ffmpeg -ss <秒> -i 素材.mp4 -frames:v 1 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920" assets/bg.jpg
  ```
- 渲染需代理：`export https_proxy=http://127.0.0.1:10080`，`npm run render` 一律后台跑

## 5. 动效约定（封面特有）

- **首帧即封面**：0-0.8s 完全静止；**封面元素禁用 `from()/fromTo()`**（immediateRender 会在 t=0 抹掉元素），动效 0.8s 后用 `to()` 接管（标题呼吸 / 卡片 1.07 依次脉冲 stagger 0.16 / 光带扫过 / 主体亮度呼吸）
- `window.__timelines["main"] = tl` 必须手动注册 + `tl.seek(0)`
- 渲染完成必须**全程逐帧抽查**（不只首尾帧）

## 6. 验收清单（生成封面后逐项核对）

- [ ] 序号顺序：顶1 / 二排2·3 / 底排4·5
- [ ] 二排 ±10° 内边上翘、底排反向 ±5°，2-4 / 3-5 无大面积重叠
- [ ] 标题三行不超宽、不出上安全区（y140 起）
- [ ] 背景与主体为不同图；主体无边框、边缘羽化过渡
- [ ] 主体顶部顶到中卡底部；底部不出 y1790
- [ ] 半透明卡文字在亮背景上可读（投影+暗化在位）
- [ ] 图标全部为内联 SVG，无 emoji
- [ ] 底排及主体底部在安全区内
